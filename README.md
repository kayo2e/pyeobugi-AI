# 펴부기 (Pyeobugi)

웹캠으로 거북목(머리 내밀기)과 고개 숙임처럼 목에 부담을 주는 자세를 감지해 바른 자세를 돕는 데스크톱 앱 (macOS / Windows).
두 자세는 구분하지 않고 하나의 "나쁜 자세"로 판정합니다 ([ADR 0002](docs/adr/0002-single-bad-posture-class.md)).

- **온디바이스 감지**: 영상, 얼굴, 자세 수치는 기기 밖으로 나가지 않고, 서버에는 익명 이벤트 로그만 전송
- **저전력**: 경량 얼굴 검출 모델 + 상태에 따라 감지 주기를 조절해 발열과 배터리 소모 최소화

## 기술 스택

Electron · React · TypeScript · Vite · MediaPipe Tasks Vision · Vitest

## 시작하기

```bash
npm install
npm run dev
```

## 브랜치 전략

| 브랜치 | 용도 |
| --- | --- |
| `main` | 릴리즈 |
| `dev` | 통합 브랜치 |
| `feature/*` | 기능 단위 개발 (`dev`에서 분기, `dev`로 머지) |

## 정확도 평가용 기록

영상은 저장하지 않고, 얼굴 키포인트 좌표와 각도·크기만 `userData/recordings/`에 JSON으로 저장합니다.

1. `npm run dev` → 바르게 앉아 **기준 잡기** → **데모 모드** 체크
2. 라벨과 시간을 고르고 **기록 시작** (기록 중에는 5Hz로 고정 샘플링)
   - **바른 자세**: 평소처럼 화면을 보며 타이핑·읽기
   - **거북목(머리 내밀기)**: 등은 그대로 두고 머리만 화면 쪽으로 내밀기
   - **고개 숙임**: 책상 위 휴대폰이나 노트 보기
   - **필기·자료 보기**: 평소처럼 노트에 적거나 종이 자료를 보다가 다시 화면 보기를 자연스럽게 반복
     (알림 없이 넘어가야 하는 짧은 숙임이 몇 초인지 재서, 고개 숙임 판정 대기 시간을 정하는 데 씀)
3. 같은 라벨을 조명·거리를 바꿔 2~3번씩 반복하면 좋습니다
4. 분석

```bash
npm run analyze              # 기본 기록 폴더 전체
npm run analyze -- <파일|폴더>
```

라벨별 각도 잡음, 바른 자세 대비 분리도(Cohen's d, 최적 임계값), 실제 엔진을 적응형 주기로 재생한 오탐·검출률,
숙임 구간 길이 분포(중앙값·p90·최대)를 표로 출력합니다.
